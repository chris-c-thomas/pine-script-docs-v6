# chart.is_renko

## Type

simple bool

## Returns

Returns [true](https://www.tradingview.com/pine-script-reference/v6/#const_true) if the chart type is Renko, [false](https://www.tradingview.com/pine-script-reference/v6/#const_false) otherwise.

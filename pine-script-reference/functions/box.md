# box()

Casts na to box.

## Syntax

```
box(x) → series box
```

## Arguments

**x (series box)** The value to convert to the specified type, usually [na](https://www.tradingview.com/pine-script-reference/v6/#var_na).

## Returns

The value of the argument after casting to box.

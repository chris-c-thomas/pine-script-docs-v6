# line.set_xy2()

Sets bar index/time and price of the second point

## Syntax

```
line.set_xy2(id, x, y) → void
```

## Arguments

**id (series line)** Line object.

**x (series int)** Bar index or bar time.

**y (series int/float)** Price.

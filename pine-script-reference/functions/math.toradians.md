# math.toradians()

Returns an approximately equivalent angle in radians from an angle measured in degrees.

## Syntax

```
math.toradians(degrees) → series float
```

## Arguments

**degrees (series int/float)** Angle in degrees.

## Returns

The angle value in radians.

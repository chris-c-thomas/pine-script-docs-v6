# label()

Casts na to label

## Syntax

```
label(x) → series label
```

## Arguments

**x (series label)** The value to convert to the specified type, usually [na](https://www.tradingview.com/pine-script-reference/v6/#var_na).

## Returns

The value of the argument after casting to label.

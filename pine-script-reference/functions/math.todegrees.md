# math.todegrees()

Returns an approximately equivalent angle in degrees from an angle measured in radians.

## Syntax

```
math.todegrees(radians) → series float
```

## Arguments

**radians (series int/float)** Angle in radians.

## Returns

The angle value in degrees.

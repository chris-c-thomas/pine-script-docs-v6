# box.set_text_halign()

The function sets the horizontal alignment of the box's text.

## Syntax

```
box.set_text_halign(id, text_halign) → void
```

## Arguments

**id (series box)** A box object.

**text_halign (series string)** The horizontal alignment of a box's text. Possible values: [text.align_left](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_left), [text.align_center](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_center), [text.align_right](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_right).

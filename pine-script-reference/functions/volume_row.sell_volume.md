# volume_row\.sell_volume()

Calculates the total "sell" volume for the volume footprint row represented by a [volume_row](https://www.tradingview.com/pine-script-reference/v6/#type_volume_row) object.

## Syntax

```
volume_row.sell_volume(id) → series float
```

## Arguments

**id (volume_row)** The reference (ID) of the [volume_row](https://www.tradingview.com/pine-script-reference/v6/#type_volume_row) object to analyze.

## Returns

The total "sell" volume for the footprint row.

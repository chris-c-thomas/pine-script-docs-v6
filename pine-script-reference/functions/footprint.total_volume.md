# footprint.total_volume()

Calculates the sum of the total "buy" volume and "sell" volume for the volume footprint represented by a [footprint](https://www.tradingview.com/pine-script-reference/v6/#type_footprint) object.

## Syntax

```
footprint.total_volume(id) → series float
```

## Arguments

**id (footprint)** The reference (ID) of the [footprint](https://www.tradingview.com/pine-script-reference/v6/#type_footprint) object to analyze.

## Returns

The total volume measured by the footprint.

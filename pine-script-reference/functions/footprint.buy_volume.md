# footprint.buy_volume()

Calculates the total "buy" volume for the volume footprint represented by a [footprint](https://www.tradingview.com/pine-script-reference/v6/#type_footprint) object.

## Syntax

```
footprint.buy_volume(id) → series float
```

## Arguments

**id (footprint)** The reference (ID) of the [footprint](https://www.tradingview.com/pine-script-reference/v6/#type_footprint) object to analyze.

## Returns

The total "buy" volume measured by the footprint.

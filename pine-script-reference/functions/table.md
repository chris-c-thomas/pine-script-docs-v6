# table()

Casts na to table

## Syntax

```
table(x) → series table
```

## Arguments

**x (series table)** The value to convert to the specified type, usually [na](https://www.tradingview.com/pine-script-reference/v6/#var_na).

## Returns

The value of the argument after casting to table.

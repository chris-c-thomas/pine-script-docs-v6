# volume_row\.up_price()

Retrieves the upper price level of the volume footprint row represented by a [volume_row](https://www.tradingview.com/pine-script-reference/v6/#type_volume_row) object.

## Syntax

```
volume_row.up_price(id) → series float
```

## Arguments

**id (volume_row)** The reference (ID) of the [volume_row](https://www.tradingview.com/pine-script-reference/v6/#type_volume_row) object to analyze.

## Returns

The upper boundary of the footprint row's price range.

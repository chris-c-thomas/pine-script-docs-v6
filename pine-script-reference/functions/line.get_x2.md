# line.get_x2()

Returns UNIX time or bar index (depending on the last xloc value set) of the second point of the line.

## Syntax

```
line.get_x2(id) → series int
```

## Arguments

**id (series line)** Line object.

## Returns

UNIX timestamp (in milliseconds) or bar index.

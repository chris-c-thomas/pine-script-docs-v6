# footprint.sell_volume()

Calculates the total "sell" volume for the volume footprint represented by a [footprint](https://www.tradingview.com/pine-script-reference/v6/#type_footprint) object.

## Syntax

```
footprint.sell_volume(id) → series float
```

## Arguments

**id (footprint)** The reference (ID) of the [footprint](https://www.tradingview.com/pine-script-reference/v6/#type_footprint) object to analyze.

## Returns

The total "sell" volume measured by the footprint.

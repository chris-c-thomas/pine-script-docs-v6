# box.set_text_valign()

The function sets the vertical alignment of a box's text.

## Syntax

```
box.set_text_valign(id, text_valign) → void
```

## Arguments

**id (series box)** A box object.

**text_valign (series string)** The vertical alignment of the box's text. Possible values: [text.align_top](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_top), [text.align_center](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_center), [text.align_bottom](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_bottom).

# ta.cum()

Cumulative (total) sum of `source`. In other words it's a sum of all elements of `source`.

## Syntax

```
ta.cum(source) → series float
```

## Arguments

**source (series int/float)** Source used for the calculation.

## Returns

Total sum series.

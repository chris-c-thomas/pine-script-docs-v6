# line()

Casts na to line

## Syntax

```
line(x) → series line
```

## Arguments

**x (series line)** The value to convert to the specified type, usually [na](https://www.tradingview.com/pine-script-reference/v6/#var_na).

## Returns

The value of the argument after casting to line.

# label.set_textalign()

Sets the alignment for the label text.

## Syntax

```
label.set_textalign(id, textalign) → void
```

## Arguments

**id (series label)** Label object.

**textalign (series string)** Label text alignment. Possible values: [text.align_left](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_left), [text.align_center](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_center), [text.align_right](https://www.tradingview.com/pine-script-reference/v6/#const_text.align_right).
